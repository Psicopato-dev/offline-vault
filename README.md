# 🔐 Офлайн-сейф — менеджер паролей для Android

Полностью офлайн: в манифесте **нет разрешения INTERNET**, сеть недоступна физически.
Данные хранятся только на телефоне, зашифрованы (AES-256-GCM, ключ из мастер-пароля
через PBKDF2-SHA256, 600 000 итераций). Ключ живёт только в памяти.

**Возможности:** записи (сервис, логин, пароль, заметка) · поиск · генератор паролей ·
копирование с автоочисткой буфера (30 с) · автоблокировка (2 мин бездействия / 1 мин в фоне) ·
запрет скриншотов · смена мастер-пароля · зашифрованная резервная копия (экспорт/импорт).

## Как получить APK (сборка в облаке GitHub, ничего ставить не нужно)

1. Создай на GitHub **приватный** репозиторий, например `offline-vault`.
2. Закинь в него содержимое этого архива (в Termux):
   ```bash
   termux-setup-storage
   pkg install -y git unzip
   mkdir ~/offline-vault && cd ~/offline-vault
   unzip ~/storage/downloads/offline-vault.zip
   git init && git add . && git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/offline-vault.git
   git push -u origin main
   ```
3. Открой репозиторий → **Actions** → сборка **Build APK** (запустится сама, ~3–5 минут).
4. Готово → вкладка **Releases** → **Latest APK** → скачай `OfflineVault.apk` и установи
   (разреши установку из неизвестных источников для браузера/файлового менеджера).

> После первой сборки бот-GitHub добавит в репозиторий файл `keystore/release.jks`
> (ключ подписи). Перед следующим `git push` сделай `git pull`.

## Обновление приложения
Изменил код → `git pull && git add . && git commit -m "..." && git push` →
новая сборка ставится **поверх** старой, данные сохраняются
(ключ подписи один и тот же).

## ⚠️ Важно
- **Репозиторий держи приватным.** В нём лежит ключ подписи; если репозиторий публичный,
  ключ увидят все.
- **Забыл мастер-пароль — данные не восстановить.** Это не баг, так устроено шифрование.
- **Делай резервные копии:** Настройки → «Резервная копия (экспорт)» → отправь себе
  в Избранное Telegram / на почту. Копия зашифрована мастер-паролем.
  Удаление приложения или очистка данных стирает хранилище.
- Очистка буфера обмена — «по возможности»: Android 10+ может запретить приложению
  трогать буфер, когда оно в фоне.
- Андроид-приложение нужно ставить только из своей сборки. Не ставь APK из чужих источников.

## Структура

